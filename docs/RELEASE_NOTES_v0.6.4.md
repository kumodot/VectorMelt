## VectorMelt v0.6.4

- **PNG scale** in *Export* (1x / 2x / 4x, default 1x): the PNG is the document size times this scale, so a 2048 document exports a 2048 PNG. Before, the PNG followed the *Curves* *Resolution* (2x by default) and came out at 4096, about twice as slow. *Resolution* now only sets the contouring grid of the vector.

Run: open `VectorMelt_v0.6.4.html`, or online at https://kumodot.github.io/VectorMelt/
